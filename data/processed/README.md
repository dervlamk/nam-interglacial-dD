# data/processed — timeslice-mean proxy δD

Timeslice-mean proxy hydrogen isotope (δD) records used in the notebooks to compare against
simulated precipitation δD. Both files cover the same two cores and the same three timeslices
(Holocene, LGM, LIG); only the δD values differ between them.

## Files

- `timeslice_mean_proxy_dDraw.csv` — the file actually read by the notebooks
  (`LGM_analyses.ipynb`, `LIG127k_analyses_PALEOCALADJUSTED.ipynb`) via
  `pd.read_csv('data/processed/timeslice_mean_proxy_dDraw.csv')`.
- `timeslice_mean_proxy_dD.csv` — not currently loaded by any notebook.

The two files' δD values differ by a near-constant offset of about **+91 to +92‰**
(`dD ≈ dDraw + ~91‰` for every cell). That consistent offset is in the range typical of the
apparent fractionation between a leaf-wax biomarker's measured δD and its source/precipitation
water δD — which would make `dDraw` the as-measured proxy values and `dD` a source-water-corrected
version.

**Confirmed (2026-08-05).** That inference was right. Both files are written by
`fig3_dDwax_timeseries.ipynb`, from two adjacent cells:

| | `timeslice_mean_proxy_dDraw.csv` | `timeslice_mean_proxy_dD.csv` |
|---|---|---|
| Quantity | δD<sub>C30</sub> — as-measured leaf wax | δD<sub>p</sub> — precipitation, after the C3/C4 ε correction |
| Mean over | `.mean(dim=['age'])` | `.mean(dim=['ensemble_n_dDp','age'])` |
| Error column | `.std(dim=['age'])` | `.std(dim=['ensemble_n_dDp','age'])` |
| Cell status | **live** | **commented out, marked `-----> DON'T USE`** |

Two independent signatures confirm it. The offset (+91.3 to +92.5‰) is the apparent
fractionation ε applied by `scripts/matlab/dDp_epsilon_calculation.m` as
`(1000 + δD) / (ε/1000 + 1) − 1000`, with ε a C3/C4 mixture of −107.8‰ (C4) and −82‰ (C3).
And every error column grows, because the δD<sub>p</sub> version includes the 2500-member
Monte Carlo ensemble dimension — most tellingly NH22P Holocene, which goes from **0.00**
(a single sample in the 0–4 ka window, so zero spread over `age` alone) to **3.30**.

Keep reading `dDraw`. The other file came from a cell its author disabled.

## Provenance

- **Source:** cores NH22P (−106.5183, 22.5183) and DSDP-480/479 (−111.62, 27.85), Gulf of
  California. C30 fatty-acid methyl ester δD, ice-volume-corrected against the LR04 benthic
  stack, on Bacon age models (see `fig2_dsdp480-479_agemodel.ipynb` for the 480/479 splice).
- **Timeslice windows:** Holocene 0–4 ka, LGM 18–24 ka, LIG 117–130 ka. Note these are *not*
  the same windows as the interglacial bands drawn on the `fig3` time series (HOL 0–11.7,
  LIG 117–130) or the MATLAB box plots (Holocene <11.7, LGM 11.7–27) — each is correct for
  its own figure.
- **Generated by:** `fig3_dDwax_timeseries.ipynb`, August 2025.

## A caveat when comparing against the model

The notebooks use these as **anomalies** (`lgm_dD − holocene_dD` vs model `dDp['lgm'] −
dDp['pi']`), so the ε offset largely cancels and using `dDraw` is defensible. But ε is not
constant across timeslices — δ¹³C is prescribed per climate state (−27.16‰ glacial, −26.67‰
interglacial), so the residual reaches **~1.15‰**:

| | anomaly from `dDraw` | anomaly from `dD` |
|---|---|---|
| NH22P LIG−Hol | +10.15‰ | +11.30‰ |
| NH22P LGM−Hol | +4.59‰ | +5.01‰ |
| DSDP LGM−Hol | −6.98‰ | −7.74‰ |
| DSDP LIG−Hol | +0.19‰ | +0.19‰ |

On the ±3‰ colorbars used in the difference maps that is not negligible. The hardcoded
`ddiff = [10.15, 0.19]  # based on raw C30 values, August 2025` in
`LIG127k_analyses_PALEOCALADJUSTED.ipynb` matches the `dDraw` anomalies exactly, so this is a
deliberate choice — recorded here so it stays one.

## Columns

| Column | Description |
|---|---|
| `core_name` | Identifier for the sediment/ice core or site |
| `lon`, `lat` | Site coordinates (decimal degrees; `lon` in -180:180 convention) |
| `holocene_dD`, `holocene_dD_1serr` | Holocene timeslice mean δD (‰) and 1σ standard error |
| `lgm_dD`, `lgm_dD_1serr` | LGM (~21 ka) timeslice mean δD (‰) and 1σ standard error |
| `lig_dD`, `lig_dD_1serr` | LIG (~127 ka) timeslice mean δD (‰) and 1σ standard error |
